```python
from PySide6.QtCore import QObject, Signal, QUrl
from PySide6.QtMultimedia import QMediaPlayer, QAudioOutput

class MusicPlayer(QObject):
    """Wrapper for QMediaPlayer with millisecond-accurate position control.

    Handles asynchronous duration loading and provides signals for
    timeline synchronization.

    Signals:
        position_changed: int (milliseconds)
        duration_changed: int (milliseconds)
        playback_state_changed: QMediaPlayer.PlaybackState
        error_occurred: str (error message)
    """
    position_changed = Signal(int)
    duration_changed = Signal(int)
    playback_state_changed = Signal(object)  # PlaybackState
    error_occurred = Signal(str)
```

Key implementation:
1. Create QMediaPlayer and QAudioOutput in __init__
2. Connect player.setAudioOutput(audio_output)
3. Forward durationChanged (arrives ASYNC after setSource)
4. Forward positionChanged for timeline sync
5. Handle errors via errorOccurred signal

Methods:
- load(file_path: str) - Load via QUrl.fromLocalFile()
- play() / pause() / stop()
- seek_ms(position_ms: int) - Check isSeekable() first
- set_volume(volume_0_to_1: float)
- get_position_ms() -> int
- get_duration_ms() -> int (may be 0 until durationChanged)
- is_playing() -> bool

```python
import numpy as np
from typing import Tuple, Dict

class WaveformCache:
    """Pre-compute downsampled waveform for fast QPainter rendering.

    Downsamples audio from 44.1kHz (88,200 samples/sec stereo) to
    pixel resolution (typically 1000-2000 points for screen width).
    Uses min/max peaks per pixel for accurate waveform shape.
    """

    def __init__(self, audio_samples: np.ndarray, sample_rate: int):
        """
        Args:
            audio_samples: 1D numpy array from librosa.load(mono=True)
            sample_rate: Sample rate (typically 22050 after librosa resampling)
        """
        self.samples = audio_samples
        self.sr = sample_rate
        self._cache: Dict[Tuple[float, float, int], Tuple[np.ndarray, np.ndarray]] = {}

    def get_peaks(self, start_sec: float, end_sec: float, pixel_width: int) -> Tuple[np.ndarray, np.ndarray]:
        """
        Return (min_peaks, max_peaks) arrays for rendering.

        Strategy: For each pixel, compute min/max of corresponding sample chunk.
        Results are cached by (start, end, width) tuple.

        Returns:
            Tuple of (min_peaks, max_peaks) arrays, each length=pixel_width
        """
```

Implementation:
1. Check cache for existing result
2. Convert time to sample indices: int(sec * sample_rate)
3. Calculate samples_per_pixel = duration_samples // pixel_width
4. For each pixel, slice samples and compute np.min/np.max
5. Cache result and return

Edge cases:
- Empty slice: return 0, 0
- start_sec >= end_sec: return empty arrays
- pixel_width > duration_samples: use 1 sample per pixel

Add LRU-style cache eviction if cache grows > 10 entries (simple dict.popitem())
