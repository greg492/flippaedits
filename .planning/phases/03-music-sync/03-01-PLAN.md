```python
class BeatDetectorWorker(QObject):
    """Worker for background beat detection - librosa is CPU intensive."""
    progress = Signal(str)  # Status updates
    finished = Signal(object, object, object)  # (beat_times, onset_envelope, tempo)
    error = Signal(str)
```

Key implementation details:
1. Use librosa.load(audio_path, sr=None, mono=True) to preserve native sample rate
2. Compute onset_strength with aggregate=np.median (robust for hip-hop/trap)
3. Call beat_track with onset_envelope, units='time', start_bpm=130
4. On empty beats or tempo=0, generate fallback grid at 130 BPM
5. Return (beat_times_array, onset_envelope, tempo_float)

Also implement a convenience function detect_beats() that creates the worker and thread, returning the results synchronously for testing.

Handle MP3 format gracefully - check for FFmpeg via subprocess and emit clear error if missing: "MP3 support requires FFmpeg. Install via: brew install ffmpeg"

IMPORTANT: Follow RESEARCH.md pitfall guidance:
- Use units='time' (not frames) to get seconds directly
- Handle empty beat array with fallback grid
