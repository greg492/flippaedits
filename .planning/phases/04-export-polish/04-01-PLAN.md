   - Handles 'before_timestamp' (segment ends at timestamp) and 'at_timestamp' (segment starts at timestamp)
   - Clamps start_ms to 0 (don't go negative)

<task type="auto">
  <name>Task 2: Create segment assembly and audio mixing functions</name>
  <files>src/processing/export.py, src/processing/__init__.py</files>
  <action>
Create export.py implementing:

1. **extract_segment(source_path, output_path, segment: VideoSegment, progress_callback) -> str:**
   - Opens source with PyAV
   - Seeks to segment.start_ms (microseconds for PyAV: start_ms * 1000)
   - Decodes video/audio frames until segment.end_ms
   - If segment.effects has 'slow_motion', apply PTS adjustment (from effects.py pattern)
   - Encodes to output_path with VideoToolbox (h264_videotoolbox with libx264 fallback)
   - Returns output_path

2. **assemble_segments(source_path, output_path, segments: List[VideoSegment], beats: np.ndarray, snap_tolerance_ms=50, progress_callback) -> str:**
   - Creates BeatSnapper with beats and tolerance
   - For each segment: snap start/end to beats within tolerance
   - Extract each segment to temp file (using extract_segment)
   - Concatenate using FFmpeg concat demuxer via PyAV:
     - Create concat list file
     - Open with format='concat', options={'safe': '0'}
     - Copy streams to output
   - Clean up temp files
   - Returns output_path

3. **mix_audio(video_path, music_path, output_path, video_volume=0.3, music_volume=0.7, trim_start_ms=0, trim_end_ms=None, progress_callback) -> str:**
   - Opens video and music containers with PyAV
   - Creates audio filter graph:
     - Two abuffer sources (video audio, music audio)
     - Two volume filters (video_volume, music_volume)
     - amix filter: inputs=2, duration=first, normalize=0
     - abuffersink
   - Copies video stream unchanged
   - Processes audio through filter graph
   - Encodes audio as AAC 48kHz stereo
   - Returns output_path

Use exact patterns from 04-RESEARCH.md (Pattern 2: Audio Mixing, Pattern 3: Beat-Synced Segment Assembly).

IMPORTANT: Ensure total volume <= 1.0 to prevent clipping. Validate at function entry.
