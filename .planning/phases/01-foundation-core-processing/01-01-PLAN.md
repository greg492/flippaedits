  <action>
Create src/processing/errors.py implementing the translate_ffmpeg_error() function from research.

The function should:
1. Accept FFmpeg stderr string as input
2. Match against common error patterns:
   - "no such file" / "does not exist" -> "Could not find the video file. Please check if the file still exists."
   - "invalid data" / "invalid argument" -> "This file format is not supported. Please use MP4 or MOV files."
   - "permission denied" -> "Cannot access this file. Please check file permissions."
   - "codec" + "not found" -> "Video codec not supported. Please convert to H.264 format."
   - "resource temporarily unavailable" -> "File is in use by another application. Please close other apps and try again."
3. Fallback: Extract last few non-bracket lines from stderr for generic error
4. Ultimate fallback: "An unexpected error occurred while processing the video."

Also export FFmpegError from av for convenience:
```python
from av import FFmpegError  # PyAV 16.0.0+ uses FFmpegError (not AVError)
```

Add type hints and docstrings.
  </action>
