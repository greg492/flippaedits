# Flippa Edits - Lacrosse Reel Auto-Editor

Mac desktop application that automatically edits lacrosse highlight videos into 20-second social media reels.

## Features (Phase 1 - In Progress)

- Drag-and-drop 4K video import
- Automatic 720p proxy generation with hardware acceleration
- Responsive GUI with background processing
- Manual timestamp marking for goals and celebrations

## Tech Stack

- Python 3.10+
- PyAV 16.1.0 (video processing)
- PySide6 6.10.1 (GUI)
- FFmpeg with VideoToolbox (Mac hardware acceleration)
